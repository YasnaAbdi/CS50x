# CS50x – Harvard University | Solutions

## About This Repository

This repository contains my personal solutions to the programming assignments from **CS50x: Introduction to Computer Science**, offered by **Harvard University**.

The main purpose of this repository is to:

* Document my learning journey.
* Track my progress throughout the course.
* Review concepts in the future.
* Showcase my programming experience.

Each solution was implemented after studying the course materials and completing the assignments independently.
